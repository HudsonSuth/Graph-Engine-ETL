Put your own SVG icon sets here, one folder per set: `explore/icons-custom/<set>/<icon-name>.svg` (lower-case names, a-z 0-9 -).
Declare each set with its licence in the style file (`symbols.iconSets.<set>.license`); undeclared or unlicensed sets are refused.
Use `currentColor` in the SVG if you want the glyph tinted to contrast with the status fill.

# PuppyGraph vs Tom Sawyer Data Streams vs StreamGraph

As of 2026-11-12. Public pages and docs only. No binaries were downloaded or run.

PuppyGraph is not a Data Streams clone. It is a zero-ETL graph query engine that queries your tables in place with openCypher and Gremlin. Tom Sawyer Data Streams and StreamGraph load records into a graph store. PuppyGraph is a lens on the warehouse; StreamGraph is a pipeline that builds a new store. The trade is freshness without a second copy versus a graph you own, built from messy streams.

**CONFIRMED.** PuppyGraph queries Iceberg, Databricks, Snowflake, Postgres and similar stores in place (https://www.puppygraph.com/, https://docs.puppygraph.com/connecting/). Optional local tables cache rows for speed; that is a cache, not a graph database. Kafka, files and APIs are not catalog types. Files must be loaded into a supported table first, and Kafka reaches it only through a store such as RisingWave or Iceberg (https://www.puppygraph.com/graph-rag, https://risingwave.com/blog/real-time-graph-analysis-pipeline-with-risingwave-and-puppygraph/). It exposes Bolt and Gremlin ports and does not capture change streams. Freshness is whatever the source already holds. Tom Sawyer Data Streams is schema-driven streaming ETL into a graph database sink, with Kafka, Confluent, SQL sources, continuous flows and CDC (https://www.tomsawyer.com/data-streams, RESEARCH.md). StreamGraph follows that model into a SQLite property graph, reading files, HTTP APIs, Kafka and polling CDC (SPEC.md, README.md).

A PuppyGraph schema maps tables to nodes and edges in JSON, in a Schema Builder or via a built-in AI assistant (https://docs.puppygraph.com/modeling/). It ships a query UI, GraphRAG, a chatbot and an MCP server (https://www.puppygraph.com/graph-rag). Enterprise adds OIDC SSO (including Keycloak), RBAC, row-level security and an audit log (https://docs.puppygraph.com/security/). Deploy in Docker, Kubernetes or a cloud marketplace. Developer is password-only, single node and two sources, marketed as free forever. Enterprise is priced on CPU and memory, with a 30-day trial (https://www.puppygraph.com/pricing). The engine is not open source; the Docker image is proprietary software from PuppyQuery Inc. Public GitHub clients and demos are Apache 2.0 (https://github.com/puppygraph/). The MSA limits Developer to non-production, non-commercial use and lets the company end that license at any time (https://www.puppygraph.com/msa, section 16). Marketing says "free forever"; the contract is narrower. **HYPOTHESIS:** Docker Hub does not publish a separate image EULA.

Tom Sawyer advertises a visual flow editor, a dynamic schema viewer and a RAG context layer, but its public pages do not name a graph query language. StreamGraph has a flow editor, live schema and simple pattern queries, not full Cypher, Gremlin, SSO or RAG. The target buyer is an enterprise data or AI team that already runs a warehouse or lakehouse. Named customers include AMD, Datadog, Coinbase and Baker Hughes. On Nov 10 2026 PuppyGraph announced a $10M Series A (total funding $15M) and said ARR grew 7x in the prior year (https://www.puppygraph.com/blog/series-a). StreamGraph is earlier: a small MIT-licensed streaming ETL tool.

## What this means if you sell StreamGraph

- Low overlap on the core bet. PuppyGraph queries a warehouse in place. StreamGraph, like Data Streams, builds a graph from streams that may not be there yet.
- Don't compete on "query your lakehouse as a graph." You will lose on scale, query languages, SSO and logos.
- Compete on "turn live, messy sources into a graph you own." Files, APIs, Kafka and CDC, plus an MIT license you can actually sell, is the open lane.
- PuppyGraph Developer is free to try but not free to productize. The cost of StreamGraph's lane is maturity: real Kafka tests, stronger CDC, auth and a query language buyers recognize.
- Treat PuppyGraph as a possible downstream, not a rival to copy. Becoming a zero-ETL lakehouse engine is a different product.
